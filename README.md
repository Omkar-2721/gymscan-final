# GymScan 2026 🏋️‍♂️🧪

AI Supplement Purity & Toxicity Scanner for Athletes & Bodybuilders.

## 🚀 One-Click Deploy on Vercel
1. Upload this repository / folder in Vercel.
2. Framework Preset: **Vite** (automatically detected).
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

## 💻 Local Development
```bash
npm install
npm run dev
```
